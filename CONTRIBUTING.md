# Contributing

Thanks for your interest in Kitten Play.

This is a personal project, so **pull requests aren't accepted**. Please don't open one.

## What you can do

- **Report a bug or share an idea:** open an issue. Include your device, browser, and which mode you were playing.
- **Report a security problem:** don't use an issue. Follow [SECURITY.md](SECURITY.md).
- **Make your own version:** the code is MIT licensed, so you're free to fork it and change it. See [LICENSE](LICENSE).
